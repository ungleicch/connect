# Connect

Daily worldwide **text-only** matching: talk to one random person per day, see only their **country** plus optional **favorite book / music / movie**, chat for ~24 hours, then optionally exchange socials—or keep the cultural spark.

> Product write-up: [`docs/CONNECT-product-writeup.md`](docs/CONNECT-product-writeup.md) · PDF: release assets / `docs/CONNECT-product-writeup.pdf`

**Linear:** [Connect project](https://linear.app/gorkbot/project/connect-2264dc8e786f)

## Status

Early planning. Architecture leaning **Telegram-first** for messaging + spam tooling; Connect owns matching, profiles, billing, translation, rankings.
